## Question 1

Why is an Issue useful before implementation begins?

Answer: An Issue records the goal, scope, requirements, and planned work before implementation begins. It creates a clear reference for what needs to be completed and helps prevent important requirements from being forgotten.

## Question 2

What is the purpose of acceptance criteria in an Issue?

Answer: Acceptance criteria define specific, testable conditions that must be satisfied before the work is considered complete. They guide implementation, reduce ambiguity, and provide a checklist for reviewing the finished work.

## Question 3

Why should both the Issue and the Pull Request be tracked in the same GitHub Project?

Answer: Tracking both items in the same Project provides one place to view the work from planning through implementation and review. It makes their relationship and current status clear and helps ensure that neither item is moved to Done too early.
